# Source Notes

This repo was distilled from Project AI / Hermes local research memory and methodology notes. The source material is not bundled because many original files are local workspace artifacts, reports, or broker/strategy-specific documents.

## Source classes used

- Project AI deep-dive synthesis.
- Claude Trading Methodology module.
- XAUUSD strategy/parity investigation notes.
- BTCUSD multi-timeframe ML direction research note.
- ETH/BTC pair trading ML research note.
- BTC/ETH all-ML edge-mining research note.
- Hermes quantitative finance/trading-system skills.

## Important caveat

This repository contains a cleaned methodology and knowledge synthesis, not a full reproducible dump of every historical dataset/report. Exact historical metrics must be re-verified from the original report or regenerated from raw data before being used in public claims.

## Publication rule

If publishing to GitHub, do not include:

- API keys or broker credentials;
- MT5 account identifiers;
- private trade logs;
- proprietary raw datasets;
- unredacted local paths if they reveal sensitive usernames/projects.

The current repo intentionally avoids shipping private raw data and account-level artifacts.
