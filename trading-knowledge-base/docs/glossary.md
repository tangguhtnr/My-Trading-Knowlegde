# Glossary

- **AUC**: ranking quality metric for binary classifiers. In finance, 0.52–0.54 can be meaningful but weak.
- **Bps**: basis points. 1 bps = 0.01%.
- **CVaR**: conditional value at risk, average loss beyond VaR threshold.
- **Drawdown**: decline from equity/balance peak to trough.
- **HTF**: higher timeframe.
- **Lookahead bias**: using future information not available at decision time.
- **OOS**: out-of-sample period not used for model/parameter selection.
- **PF**: profit factor = gross profit / gross loss.
- **Walk-forward**: rolling chronological train/test validation.
- **WR**: win rate.
